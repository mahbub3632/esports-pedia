# Phase 1 সেটআপ গাইড (Supabase)

একটা একটা করে ধাপ করুন। কোনো ধাপে আটকে গেলে স্ক্রিনশট পাঠান।
(Supabase-এর মেনুর নাম মাঝে মাঝে বদলায়, কাছাকাছি নামের অপশন খুঁজুন।)

## ধাপ ১: Supabase অ্যাকাউন্ট ও প্রজেক্ট
1. supabase.com খুলুন, **Start your project** চাপুন, GitHub অ্যাকাউন্ট দিয়ে সাইন ইন করুন।
2. **New project** চাপুন।
   - Name: `esports-pedia`
   - Database Password: একটা শক্ত পাসওয়ার্ড দিন এবং কোথাও লিখে রাখুন (আমাকে পাঠাবেন না)।
   - Region: বাংলাদেশের সবচেয়ে কাছের (সাধারণত Singapore)।
   - Plan: Free।
3. **Create new project** চাপুন। ২-৩ মিনিট অপেক্ষা করুন।

## ধাপ ২: ডেটাবেসের টেবিল বানানো
1. বাঁ মেনুতে **SQL Editor** চাপুন, তারপর **New query**।
2. `supabase/schema.sql` ফাইলটা Notepad-এ খুলে সব লেখা কপি করুন (`Ctrl+A`, `Ctrl+C`)।
3. SQL Editor-এ পেস্ট করে **Run** চাপুন।
4. নিচে "Success" দেখালে ঠিক আছে। লাল ত্রুটি দেখালে পুরো ত্রুটিটার স্ক্রিনশট পাঠান।

## ধাপ ৩: শুরুর ডেটা
নতুন একটা Query খুলে `supabase/seed.sql`-এর লেখা পেস্ট করে **Run** চাপুন।
এতে মেনু, হোমপেজের কার্ড, Free Fire গেম ও চারটা রোল (Rusher, IGL, Sniper, Bomber) বসবে। কোনো ভুয়া টিম বা প্লেয়ার বসে না।

## ধাপ ৪: আপনার অ্যাডমিন অ্যাকাউন্ট
1. বাঁ মেনুতে **Authentication**, তারপর **Users**, তারপর **Add user**, তারপর **Create new user**।
2. আপনার ইমেইল ও একটা শক্ত পাসওয়ার্ড দিন। **Auto Confirm User** টিক দিন। **Create user** চাপুন।
3. নতুন Query খুলে `supabase/make-admin.sql`-এর লেখা পেস্ট করুন। `PUT-YOUR-ADMIN-EMAIL-HERE`-এর জায়গায় ওই ইমেইল বসান, তারপর **Run**।

## ধাপ ৫: সবার রেজিস্ট্রেশন বন্ধ করা
**Authentication** এর সেটিংসে (Sign In / Providers অথবা Settings) **Allow new users to sign up** বন্ধ করুন (Off) এবং Save করুন।
এতে শুধু আপনিই লগইন করতে পারবেন।

## ধাপ ৬: দুটো তথ্য কপি করা
1. **Project Settings**, তারপর **API** (অথবা API Keys) খুলুন।
2. **Project URL** কপি করুন।
3. **anon / publishable** কী কপি করুন।
4. `js/config.js` ফাইলটা Notepad-এ খুলে `PASTE_...` লেখার জায়গায় দুটো বসান, Save করুন।

**সাবধান:** `service_role` বা `secret` লেখা কী কখনো কপি করবেন না, এই ফাইলে বা কাউকে পাঠানোর সময় না। ওটা পুরো ডেটাবেসের চাবি।

## ধাপ ৭: পরীক্ষা
`setup-check.html` ফাইলে ডাবল ক্লিক করুন (ইন্টারনেট চালু থাকতে হবে)।
পাঁচটা লাইনই সবুজ **OK** দেখালে Phase 1 শেষ।

## মনে রাখবেন
- ফ্রি প্ল্যানের সীমা আছে: আমার জানা মতে অনেকদিন ব্যবহার না হলে ফ্রি প্রজেক্ট বিরতিতে (pause) যেতে পারে, আর স্টোরেজ ও ডেটার সীমাও আছে। শর্ত বদলায়, তাই Supabase-এর Pricing পেজে দেখে নিন।
- Supabase Dashboard-এ **Database**, তারপর **Backups** দেখুন। ডেটা জমতে শুরু করলে নিয়মিত ব্যাকআপ বা এক্সপোর্ট রাখবেন।
- আপনার পুরোনো GitHub সাইট এখন ছুঁইবেন না। নতুন সাইট সম্পূর্ণ হয়ে পরীক্ষা শেষ হলেই বদলানো হবে।
