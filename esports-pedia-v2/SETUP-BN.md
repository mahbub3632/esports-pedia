# Esports Pedia – সম্পূর্ণ সেটআপ গাইড (বাংলা)

**গুরুত্বপূর্ণ:** এই প্রজেক্ট Claude শুধু **নকল (simulated) Supabase**-এ পরীক্ষা করেছে। **আসল Supabase ও আসল Netlify-তে এখনো পরীক্ষা হয়নি।** প্রথমবার চালানোর সময় কোনো ত্রুটি এলে স্ক্রিনশট নিয়ে ঠিক করে নিন।

GitHub রিপোজিটরি: `mahbub3632/esports-pedia`

একটা একটা করে ধাপ করুন। আটকে গেলে স্ক্রিনশট পাঠান।
(Supabase ও Netlify-এর মেনুর নাম মাঝে মাঝে বদলায়, কাছাকাছি নামের অপশন খুঁজুন।)

---------------------------------------------------------------
## ভাগ ১: Supabase (ডেটাবেস, লগইন, ছবির স্টোরেজ)

### ধাপ ১: প্রজেক্ট খোলা
1. supabase.com খুলুন, **Start your project** চাপুন, GitHub দিয়ে সাইন ইন করুন।
2. **New project** চাপুন। Name: `esports-pedia`। Database Password: শক্ত পাসওয়ার্ড দিন ও লিখে রাখুন (কাউকে পাঠাবেন না)।
3. Region: বাংলাদেশের সবচেয়ে কাছেরটা (সাধারণত Singapore)। Plan: Free। **Create new project** চাপুন, ২-৩ মিনিট অপেক্ষা করুন।

### ধাপ ২: SQL চালানো (পরপর চারটা, এই ক্রমে)
বাঁ মেনুতে **SQL Editor**, তারপর **New query**। প্রতিটা ফাইল Notepad-এ খুলে সব লেখা কপি করে পেস্ট করুন, **Run** চাপুন। "Success" দেখাতে হবে।
1. `supabase/schema.sql`
2. `supabase/seed.sql`
3. `supabase/migration-002.sql`
4. `supabase/migration-003.sql` (মেনুতে **Statistics** লিংক ফিরিয়ে আনে)

লাল ত্রুটি এলে পুরো ত্রুটির স্ক্রিনশট পাঠান। (আগেই কিছু চালিয়ে থাকলে শুধু বাকিগুলো চালান। Statistics পেজ ঠিক করতে এখন শুধু `migration-003.sql` দরকার। সবগুলো আবার চালালেও সমস্যা নেই।)

### ধাপ ৩: আপনার অ্যাডমিন অ্যাকাউন্ট
1. **Authentication**, তারপর **Users**, তারপর **Add user**, তারপর **Create new user**।
2. আপনার ইমেইল ও শক্ত পাসওয়ার্ড দিন। **Auto Confirm User** টিক দিন। **Create user** চাপুন।
3. নতুন Query খুলে `supabase/make-admin.sql` পেস্ট করুন। `PUT-YOUR-ADMIN-EMAIL-HERE`-এর জায়গায় ওই ইমেইল বসিয়ে **Run** চাপুন।

### ধাপ ৪: সবার রেজিস্ট্রেশন বন্ধ
**Authentication**-এর সেটিংসে (Sign In / Providers) **Allow new users to sign up** বন্ধ (Off) করে Save করুন।
এতে শুধু আপনিই লগইন করতে পারবেন।

### ধাপ ৫: দুটো তথ্য কপি করে `js/config.js`-এ বসানো
1. **Project Settings**, তারপর **API** (বা API Keys) খুলুন।
2. **Project URL** ও **anon / publishable** কী কপি করুন।
3. `js/config.js` ফাইল Notepad-এ খুলে `PASTE_...` লেখার জায়গায় বসান, Save করুন।

**সাবধান:** `service_role` / `secret` কী কখনো কপি করবেন না, কোনো ফাইলে বা কাউকে পাঠানোর সময় না।

## ভাগ ২: GitHub-এ আপলোড (পুরোনো ফাইল না মুছে)

আপনার Netlify-র Base Directory হলো `esports-pedia-v2`। তাই নতুন প্রজেক্ট ওই নামের ফোল্ডারে যাবে।

1. জিপ এক্সট্র্যাক্ট করুন। ভেতরে `esports-pedia-v2` নামের একটা ফোল্ডার পাবেন।
2. github.com/mahbub3632/esports-pedia খুলুন।
3. **Add file**, তারপর **Upload files** চাপুন।
4. `esports-pedia-v2` **ফোল্ডারটা নিজে** টেনে এনে ছাড়ুন (ভেতরের ফাইল আলাদা করে নয়)।
5. আপলোড শেষ হলে **Commit changes** চাপুন।

পুরোনো ফাইলগুলো এখন যেখানে আছে সেখানেই থাকবে, কিছু মুছবে না। নতুন সাইট ঠিকমতো চলার পর পুরোনো ফাইল মুছে ফেলতে পারবেন (ভাগ ৪)।
`config.js`-এ আপনার anon কী বসানো আছে কিনা আপলোডের আগে আবার দেখে নিন।

### আগেই আপলোড করে থাকলে: শুধু নতুন ফাইল দিন (Statistics আপডেট)
**সাবধান:** পুরো ফোল্ডার আবার আপলোড করলে আপনার `js/config.js`-এর আসল কী মুছে গিয়ে ফাঁকা (PASTE_...) হয়ে যাবে। তাই `statistics-update.zip` ব্যবহার করুন, এতে `config.js` নেই।
1. `statistics-update.zip` এক্সট্র্যাক্ট করুন, ভেতরে `esports-pedia-v2` ফোল্ডার পাবেন।
2. GitHub-এ **Add file**, তারপর **Upload files**, ফোল্ডারটা টেনে ছাড়ুন, **Commit changes** চাপুন। একই নামের ফাইল বদলে যাবে।
3. Supabase-এ `migration-003.sql` চালান।
4. Netlify নিজে নতুন করে প্রকাশ করবে। ১-২ মিনিট পর `আপনার-সাইট/statistics/` খুলুন।

## ভাগ ৩: Netlify-তে প্রকাশ

1. app.netlify.com খুলুন, GitHub দিয়ে সাইন ইন করুন।
2. **Add new site**, তারপর **Import an existing project**, তারপর **GitHub**।
3. রিপোজিটরি `mahbub3632/esports-pedia` বেছে নিন।
4. সেটিংস:
   - **Base directory:** `esports-pedia-v2`
   - **Build command:** ফাঁকা রাখুন
   - **Publish directory:** ফাঁকা রাখুন (ফাইলটাই `netlify.toml`-এ `.` দেওয়া আছে)
5. **Deploy** চাপুন। ১-২ মিনিটে সাইটের ঠিকানা (`নাম.netlify.app`) পাবেন।
6. সাইট খুলে হোমপেজ দেখুন। `/admin/` ঠিকানায় গিয়ে লগইন করুন।

**যদি "Page not found" দেখায়:** Site configuration, তারপর Build & deploy-এ গিয়ে **Publish directory** ঘরে `esports-pedia-v2` লিখে Save করুন, তারপর আবার Deploy করুন।

এরপর থেকে GitHub-এ কোনো কোড ফাইল বদলালে Netlify নিজে নতুন করে প্রকাশ করবে। কিন্তু **তথ্য** (টিম, প্লেয়ার ইত্যাদি) বদলাতে GitHub লাগবে না, অ্যাডমিন প্যানেল থেকেই হবে।

## ভাগ ৫: অ্যাডমিন প্যানেল কীভাবে চালাবেন

ঠিকানা: `আপনার-সাইট/admin/`। ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন।

**প্রথমবার এই ক্রমে তথ্য দিন:**
1. **Games**: Free Fire আগেই আছে (Published করুন)।
2. **Organizations** (থাকলে)।
3. **Teams**: নাম, লোগো আপলোড, গেম, র‍্যাঙ্ক, **Published** টিক দিন।
4. **Players**: নাম, ছবি, রোল, বর্তমান টিম, **Published** টিক দিন। ক্রম ঠিক করতে **Player Order** খুলে টেনে সাজান।
5. **Tournaments**, তারপর **Tournament Teams**, **Match Schedule**, **Results**।
6. **Transfers**: Published করলে খেলোয়াড়ের বর্তমান টিম নিজে বদলে যায়।
7. **Rankings → Ranking Entries**: Top Rusher, IGL, Sniper, Bomber-এর তালিকা হাতে বসান। নতুন রোল চাইলে **Ranking Roles**, তারপর **Rankings**।
8. **Earnings**: টিম ও খেলোয়াড়ের মোট আয়। মুদ্রার চিহ্ন (৳ বা BDT) **Settings**-এ `currency` ঘরে দিন।
9. **News, Player Spotlight, Media Outlets**।
10. **Homepage Sections / Tiles / Navigation Menu**: হোমপেজের অংশ ও মেনুর ক্রম, দেখানো বা লুকানো।
11. **Contributions**: দর্শকদের পাঠানো আবেদন দেখে Approve বা Reject করুন।

**মনে রাখবেন:**
- কিছু **Published** টিক না দিলে সেটা পাবলিক সাইটে দেখা যাবে না।
- কোনো ছবি ৫ MB-এর বেশি হলে আপলোড হবে না। শুধু PNG, JPG, WEBP।
- মোছার আগে সবসময় নিশ্চিত করতে বলা হবে।

## ভাগ ৬: সৎ সীমাবদ্ধতা (পড়ে নিন)

- এই প্রজেক্ট আমি **সিমুলেটেড Supabase** দিয়ে ব্রাউজারে পরীক্ষা করেছি (৮৭টা পরীক্ষা সফল)। কিন্তু **আসল Supabase, আসল ডেটাবেসে SQL এবং আসল Netlify-তে** পরীক্ষা করা সম্ভব হয়নি। প্রথম চালানোয় কোনো ত্রুটি এলে স্ক্রিনশট পাঠান।
- সুন্দর লিংক (`/teams/team-alpha`) শুধু Netlify-তে কাজ করে। ফাইলে ডাবল ক্লিক করলে বা GitHub Pages-এ কাজ করবে না।
- র‍্যাঙ্কিং এখন হাতে (manual) দিতে হয়, নিজে হিসাব হয় না।
- Contributions-এ Approve করলে তথ্য নিজে সাইটে যোগ হয় না, আপনাকে নিজে যোগ করতে হবে।
- Transfers মুছলে খেলোয়াড়ের টিম আগের অবস্থায় ফেরে না, টিম নিজে ঠিক করে নিন।
- Supabase ফ্রি প্ল্যানে (আমার জানা মতে) অনেকদিন ব্যবহার না হলে প্রজেক্ট বিরতিতে যেতে পারে, আর স্টোরেজ ও ডেটার সীমা আছে। Supabase-এর Pricing পেজে দেখে নিন। নিয়মিত ব্যাকআপ রাখুন।
- সার্চ সরল (নামের অংশ মিললেই দেখায়)। প্রতিটা পেজ প্রকাশিত সব টিম ও প্লেয়ার একসঙ্গে লোড করে, কয়েকশ পর্যন্ত ঠিক আছে।
- অ্যাডমিনের জন্য খুব শক্ত পাসওয়ার্ড ব্যবহার করুন। Supabase-এ দুই ধাপের লগইনের (MFA) সুবিধা আছে, চালু করতে পারেন।
